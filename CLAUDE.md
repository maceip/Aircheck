## UI rules

- All Android UI must use the components in `app/src/main/java/com/example/ui/design` (AcTokens, AcType, AcComponents) as specified in [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md). Do not hand-roll buttons, colors, text styles, outlines or accent bars.
- Any new component or visual change needs Ryan's approval first.
